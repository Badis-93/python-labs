## 📸 Задача 1. Кубы чисел

### Код

number = int(input('Введите число: '))
current_number = 1
while current_number <= number:
    print(current_number, '** 3 =', current_number ** 3)
    current_number += 1

### Как работает
- Пользователь вводит число N.
- Счётчик current_number начинается с 1.
- Цикл while выполняется, пока счётчик не превысит N.
- На каждой итерации выводится число в кубе и счётчик увеличивается на 1.

### Что использовано
- Цикл while
- Счётчик current_number
- Оператор ** для возведения в степень

## 📸 Задача 2. Слишком большие числа

### Код

number = int(input('Введите число: '))
count = 0
if number == 0:
    count = 1
else:
    while number > 0:
        number = number // 10
        count += 1
print('Количество цифр в числе:', count)

### Как работает
- Если число 0 — счётчик сразу равен 1 (по условию задачи).
- Иначе цикл while отсекает последнюю цифру через // 10 и увеличивает счётчик.
- Цикл работает, пока число не станет 0.

### Что использовано
- Цикл while
- Счётчик count
- Целочисленное деление //
- Условный оператор if / else
- Решение не использует строки — как требовалось в задании

## 📸 Задача 3. Обычный день на работе

### Код

total_tasks = 0
took_call = False
hour = 1
while hour <= 8:
    print(hour, '-й час')
    tasks = int(input('Сколько задач решит Максим? '))
    total_tasks += tasks
    if not took_call:
        call = int(input('Звонит жена. Взять трубку? (1 - да, 0 - нет): '))
        if call == 1:
            took_call = True
    hour += 1
print('Рабочий день закончился. Всего выполнено задач:', total_tasks)
if took_call:
    print('Нужно зайти в магазин')

### Как работает
- Цикл while выполняется 8 раз (рабочий день).
- На каждом часу спрашивается количество задач, они суммируются в total_tasks.
- Если Максим ещё не брал трубку (`not took_call`), спрашивается про звонок жены.
- Если взял (call == 1) — флаг took_call становится True, и больше про звонок не спрашивают (дополнительное условие).
- В конце выводится количество задач и, если флаг True, сообщение про магазин.

### Что использовано
- Цикл while
- Логический флаг took_call (True/False)
- Оператор not
- Условные операторы if
- Счётчик total_tasks
- Счётчик hour

## 📸 Задача 4. Вклады

### Код

x = int(input('Какая сумма вклада: '))
p = int(input('Какой ежегодный процент вклада: '))
y = int(input('Сумма порога: '))
years = 0
while x < y:
    x = x + (x * p) // 100
    years += 1
print('Количество лет для достижения порога:', years)

### Как работает
- Вводятся три числа: X (начальный вклад), P (процент), Y (порог).
- Цикл while работает, пока вклад меньше порога.
- На каждой итерации к вкладу прибавляется P процентов (дробная часть отбрасывается через //).
- Счётчик years увеличивается.
- Когда вклад достигает Y — цикл завершается, выводится количество лет.

### Что использовано
- Цикл while
- Целочисленное деление //
- Счётчик years
- Формула x = x + (x * p) // 100

## 📸 Задача 5. Игра «Угадай число»

### Код

secret = 3
attempts = 0
while True:
    number = int(input('Загадайте число от 1 до 10: '))
    attempts += 1
    if number < secret:
        print('Число меньше, чем нужно. Попробуйте еще раз')
    elif number > secret:
        print('Число больше, чем нужно. Попробуйте еще раз')
    else:
        print('Вы угадали! Число попыток:', attempts)
        break

### Как работает
- Загаданное число хранится в переменной secret (по примеру — 3).
- Бесконечный цикл while True запрашивает число у пользователя.
- Счётчик attempts увеличивается на каждой попытке.
- Если число меньше — подсказка «меньше». Если больше — «больше».
- Если угадал — выводится число попыток и цикл прерывается через break.

### Что использовано
- Бесконечный цикл while True
- Оператор break
- Счётчик attempts
- Условные операторы if / elif / else

## 🔐 Практическая значимость
Циклы и условия — база любого языка программирования. В кибербезопасности эти конструкции используются в:
- скриптах для анализа логов (перебор строк, подсчёт событий);
- автоматизации задач (проверка условий, повтор действий);
- парсинге данных (обход списка адресов, проверка портов);
- генерации отчётов (счётчики, флаги, условия);
- написании утилит для пентеста (перебор паролей, сканирование портов).

Понимание while, break и логических флагов — фундамент для написания скриптов автоматизации в ИБ.
